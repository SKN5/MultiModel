# MultiModel

A multi-model AI chat interface powered by Puter.js.

## Features

- Dynamic model discovery through Puter.js
- Multiple AI providers/models in one selector
- Streaming responses
- Multi-turn conversations
- Local chat history
- Responsive UI
- No custom backend required
- Designed for GitHub Pages

## Run

Open `index.html` through a static web server or GitHub Pages.

Puter.js is loaded from:

`https://js.puter.com/v2/`

The app uses Puter's browser AI APIs, so model availability and usage are handled by Puter.

## GitHub Pages

After the files are pushed, enable GitHub Pages for the repository's default branch under:

Settings → Pages → Deploy from a branch
